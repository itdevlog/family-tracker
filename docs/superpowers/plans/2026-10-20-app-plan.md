# Family Tracker Android App — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Android-приложение (Kotlin + Compose) с ролями «родитель» (карта/история/SOS) и «ребёнок» (фоновый трекинг + SOS-кнопка), работающее с сервером по плану `2026-10-20-server-plan.md`.

**Architecture:** Один APK, выбор роли при первом запуске. Manual DI (`AppContainer`), Retrofit-подобный Ktor Client поверх контракта сервера; child mode — foreground service + FusedLocationProvider + Room-буфер; parent mode — osmdroid карта, Ktor WS `/live`, ntfy-подписка отдельным сервисом.

**Tech Stack:** Kotlin 2.x, Jetpack Compose, minSdk 26, targetSdk 35, Ktor Client 3, Room, WorkManager, osmdroid 7, ZXing core (QR-генерация), ML Kit barcode (QR-сканирование), EncryptedSharedPreferences.

**Spec:** `docs/superpowers/specs/2026-10-20-family-tracker-design.md`
**Server plan:** `docs/superpowers/plans/2026-10-20-server-plan.md` (контракт API — без изменений)

## Global Constraints

- Пакет `ru.family.tracker`; minSdk 26, targetSdk 35
- Разрешения: `ACCESS_FINE_LOCATION`, `ACCESS_BACKGROUND_LOCATION`, `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_LOCATION`, `POST_NOTIFICATIONS`, `RECEIVE_BOOT_COMPLETED`
- Токен/роль/baseUrl/ntfy-конфиг — в EncryptedSharedPreferences
- Интервалы: движение (speed > 1 м/с) → 10 с HA; покой → 60 с BALANCED
- Батчи ≤ 100 точек (Room → Ktor Client), оффлайн → копить, шлём при сети
- SOS: длинное нажатие 2000 мс с прогресс-кольцом; оффлайн → сохранить, отправить при сети
- WS обрыв → догоняем `GET /locations` с момента последней точки; backoff 2/4/8/16/30 с
- QR-код pair: payload `{"server":"https://api.<домен>","code":"123456"}`
- Тесты android-сервисов — Robolectric, чистая логика — JUnit; UI — сборка + ручные сценарии

## Review Focus

1. **Телефон в Doze** — точки должны продолжать приходить (fg service + WorkManager fallback). Ручной сценарий, Task 6.
2. **Перезапуск телефона** — сервис сам стартует (BOOT_COMPLETED). Тест Robolectric, Task 6.
3. **Убийство OEM (Xiaomi/EMUI)** — wizard открывает конкретные экраны, а не «инструкция» текстом. Ручная проверка Task 8.
4. **SOS при отсутствие сети у ребёнка** — событие сохраняется и уходит позже. Тест Robolectric/логики, Task 7.
5. **WS отвалился** — карта не «замирает»: догоняем через REST. Тест логики LiveMonitor, Task 10.
